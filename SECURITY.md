# Security Policy

Siemens takes the security of its code seriously. If you think you have found a security vulnerability,
please read the next sections and follow the instructions to report your finding.

If you suspect an actively exploited vulnerability or a severe security incident involving this repository, please contact ROS# project team immediately at [ros-sharp.ct@siemens.com](mailto:ros-sharp.ct@siemens.com). Our security response team is here to respond quickly and support the necessary escalation and reporting steps.

## Scope of this policy

This is the **security policy for ROS#** on GitHub.com.

It does not apply for other repositories.
It also does not apply for forks where you should follow the upstream policy instead.

## Reporting a Vulnerability

Please DO NOT report any potential security vulnerability via a public channel (mailing list, GitHub issue, etc.).
Instead, [report the vulnerability privately via GitHub](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing/privately-reporting-a-security-vulnerability)
(if enabled for the repository) or [contact us via email](mailto:ros-sharp.ct@siemens.com).

Please provide a detailed description of the issue, the steps to reproduce it, the affected version(s) and, if already available, a proposal for a fix.
